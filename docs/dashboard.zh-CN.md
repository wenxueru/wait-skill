# Wait 看板

## 打开当前会话

使用 Python 3.11 或更新版本，传入当前对话的会话 ID：

```sh
python /path/to/wait/src/waitctl.py dashboard --session "$AGENT_SESSION_ID"
```

请打开命令返回的 HTTP 地址；`src/wait/dashboard/index.html` 依赖服务，不能直接作为 `file://` 页面打开。追加 `&view=graph` 可直接进入图视图。

页面默认英文、浅色。「设置」可切换语言与外观；偏好保存在当前浏览器地址下，端口改变后使用默认值。

## 会话范围

| 页头选项 | 显示内容 |
| --- | --- |
| **当前会话** | 打开 URL 时的原始会话 |
| 某个会话 ID | 仅该会话的等待、循环与目标 |
| **全部会话** | 当前 waitd 上所有已登记任务 |

- 打开菜单才加载已知会话 ID 和任务数量，可按 ID 搜索。其他会话的任务内容不会混入选中会话的状态和事件流。
- 切换保留当前任务入口和列表／图视图，清除原任务定位，并保留返回原始会话的入口。
- `dashboard` 使用 `CODEX_THREAD_ID` 或显式 `--session`。无会话的 URL 不显示任务；`--all-sessions` 主动开启本机总览。
- `dashboard --state /absolute/path/goal.json` 登记已有 DAG；未选择会话时使用其所属会话，不从最近任务或标签页推断归属。

## 分享更新

- Wait/Loop/Goal 命令返回定位所属会话、任务和节点的 `dashboard_url`。保留完整查询参数，复用可访问的转发地址。
- 首次介绍任务、进度／状态／结果／阻塞有实质变化，或用户索要时附链接；普通回复和无变化的回调不重复附。

## 三种任务视图

| 入口 | 记录与详情 | 图视图 |
| --- | --- | --- |
| **等待** | 独立及所属等待器的查询、通知、结果和完整事件说明 | 已记录的目标／循环归属及已知目标依赖 |
| **循环** | 轮次、计划、截止时间与执行历史 | 所属目标及聚合循环卡片 |
| **目标** | DAG 节点、验收条件、结果与最终验收 | 实际任务依赖 |

- 顶部只保留这三个入口，计数包含已有历史；未指定 `mode` 时默认打开等待。
- 共用列表、筛选、排序和详情。图中的上下文节点可以查看，但不重复计入任务数。
- 独立等待之间不推测连线，关联图不会创建新的调度状态。

## 列表和详情

### 显示范围与筛选

| 范围 | 记录 |
| --- | --- |
| **当前任务**（默认） | 未结束任务，包含失败 |
| **历史** | 已完成、已取消 |
| **全部** | 两者，不删除历史 |

- 按标题或 ID 搜索。状态复选菜单和统计卡支持多选，匹配任一已选状态即可显示；状态菜单中的「全部任务」清除该限制。
- 选择历史状态时按需进入历史，混选当前与历史状态则进入全部。空结果保留筛选控件和历史入口。
- 切换会话保留任务范围，切换等待／循环／目标入口恢复当前任务。直接链接可定位已结束记录。

### 列与任务跳转

| 列 | 内容 |
| --- | --- |
| **依赖任务／所属任务** | 已记录的任务链接，没有关系显示「无」 |
| **下一步** | 原始事件说明，没有则为 `—`；不从结果推测动作 |
| **状态** | 悬浮、聚焦或点按查看该类任务的含义 |
| **耗时／最近更新** | 降序 → 升序 → 默认；未知值排最后 |

- 链接定位具体任务并支持新标签页。目标不可用时保留文字，不跳到其他任务。
- 选择任务查看完整说明、时间、证据和关联任务。所属等待器通过其目标或循环控制。
- 默认优先显示失败、执行中和可推进任务。实时更新保留筛选、排序和编辑草稿，耗时排序不丢失焦点。

## 时间

- 耗时优先显示当前执行或等待阶段，详情另列包含等待的总历时。浏览器每秒本地计时，不轮询网络或唤醒 Agent。
- 目标节点处理回调后，执行阶段重新计时，总历时保留原起点；等待器从提交起计时，循环从初始化起计时，阶段时间随轮次／计划事件变化。
- 结束后的时间固定不变；缺少记录时显示「尚未开始」或 `—`。时间点使用浏览器时区，悬停可看完整值。

## 图操作

- Dagre 减少交叉。当前／历史图隐藏无关已结束记录，保留必要祖先和当前计时器；目标在同一任务范围内按状态／关键词淡化节点、保持布局，等待／循环图则适应匹配的关系子图。「全部」恢复完整图。
- 用滑块、加减按钮、Ctrl + 滚轮或触控板捏合缩放。鼠标、触屏或笔可从任意位置（含节点）拖动平移，普通滚轮也可平移；轻点查看节点，拖动不触发选中。
- 整图适应窗口后仍能平移，实时更新保留位置。「适应窗口」重新居中，「100%」恢复原始大小；聚焦图后可用 `+`／`−`、`0`、`f` 操作。
- Loop 计时器折叠进所属循环卡片：展示轮次、间隔／下次执行、最近结果及匹配的计时器／失败数量。
- Loop 详情提供最近五个完成轮次和折叠的计时历史；每条记录可打开原始等待。筛选仍按原记录计算，不删除状态。
- 图操作和连线说明收在 **?** 中，悬浮、聚焦或点按查看；任务说明和结果保留完整原文。
- 资源本地打包，不依赖 CDN，也不需要 Agent 维护页面。

## 操作任务

| 操作 | 效果 |
| --- | --- |
| 添加节点 | 保存标题、类型、依赖、验收条件与读写范围 |
| 编辑待处理节点 | 修改标题、依赖和验收条件 |
| 重试失败节点 | 恢复为待处理；Agent 仍需确认外部操作是否获准重试 |
| 暂停／恢复 Goal | 停止／允许新派发 |
| 取消 Goal | 将未完成节点标为取消，保留已完成结果 |
| 取消 Wait／Loop | 停止等待程序／阻止后续循环轮次 |

Goal 的暂停和取消不终止已运行的 Agent 或外部作业。页面操作修改保存状态；需要 Agent 立即行动时，在对话中发消息。

## Agent 与页面如何协作

- 照常使用 Wait/Loop/Goal 命令，waitd 自动生成页面；Agent 不编写 HTML、不维护页面摘要、不做额外确认。
- CLI 和页面共用任务状态与命令队列。派发前重读状态，尊重用户编辑、暂停和取消。
- SSE 推送变化，不由模型轮询，也不启动新轮次。
- 状态接口、SSE 和操作接口使用 URL 中的会话范围。一个系统用户共用默认 waitd；会话范围是筛选，不是身份认证。独立状态文件隔离任务，共用文件即共同控制。
- Goal/Loop 命令按模式串行，watcher 并发执行，事件投递到所属会话。

需要手动接续时，使用 `start -- --session ID --no-notify ...` 或 `loop -- init --session ID --no-notify ...`，保留会话归属并关闭自动唤醒。通过 `waitctl follow ID --timeout SECONDS` 阻塞等待，再按模式正常处理事件，包括 Loop 的 `begin`/`complete`。

## 应用预览与远程访问

服务绑定 `127.0.0.1`，应用预览或 SSH 转发可能将它映射到其他回环主机名和端口。保留所有原查询参数，包括 session、mode、focus、node 和 view。

已知映射地址时：

```sh
python /path/to/wait/src/waitctl.py dashboard --session "$AGENT_SESSION_ID" --base-url http://localhost:63671
```

`--base-url` 只修改输出的 URL，保留查询参数，不建立转发或修改 waitd 配置。

SSH 两端端口可以不同。以下将本机 63671 端口转发到远程看板的 35857 端口：

```sh
ssh -N -L 127.0.0.1:63671:127.0.0.1:35857 HOST
```

随后打开 `http://localhost:63671/` 并附上原查询参数，或使用上面的 `--base-url` 生成完整链接。

- 使用 HTTP，主机名为 `localhost`、`127.0.0.1` 或 `[::1]`；显式端口范围为 1–65535。
- 请求带 `Origin` 时，协议、主机名和实际端口必须与请求 URL 一致。
- 看板没有多用户身份验证，转发监听地址应保持为回环地址。

## 更新运行中的安装

修复预览访问时保持活动 waitd 运行。版本不匹配不会停止现有服务：先使用与它匹配的安装，等活动 watcher 结束后，按[服务生命周期](waitd.zh-CN.md#服务生命周期)切换版本。
